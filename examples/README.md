# Coastal Light source example

[`coastal-light.json`](coastal-light.json) is the reproducible input for an original 52-part lighthouse with 22 building steps. It demonstrates the model-to-instructions workflow; no generated renders, PDFs or development variants are included here. Run it using the commands in the [main README](../README.md).
