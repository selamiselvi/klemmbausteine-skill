# Klemmbausteine Skill

A skill and supporting tools for creating brick models with your own local coding agent.

## Status

Initial project scaffold. The skill and generation tools are not implemented yet.

## Planned output

- A machine-readable brick model and building steps.
- Four consistent isometric renders on a white background.
- Illustrated PDF instructions and a parts CSV.
- Versioned metadata and validation results.
- A ZIP bundle for sharing.

Community submission is optional: after the creator chooses to submit, the skill packages the outputs and directs them to send a file-transfer download link by email. Submission details will be added before release.

The website, moderation tools and publishing credentials belong to a separate private project.
